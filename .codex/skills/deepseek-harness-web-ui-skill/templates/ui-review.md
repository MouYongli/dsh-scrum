## Review checklist

- [ ] Plugin purpose is clear.
- [ ] Task and run are clearly distinguished.
- [ ] Current state is explicit.
- [ ] Waiting and blocked states are visible.
- [ ] Approval scope is understandable.
- [ ] Tool calls have readable summaries.
- [ ] Artifacts have provenance.
- [ ] Errors provide recovery actions.
- [ ] Keyboard navigation works.
- [ ] Focus states are visible.
- [ ] Narrow layouts remain usable.
- [ ] Raw logs are secondary to structured status.
