# Responsive Web Design

## Wide desktop

A three-region layout may be appropriate:

- navigation;
- main workspace;
- context panel.

## Standard desktop

Keep the main workspace dominant.

Allow the context panel to collapse.

## Tablet or narrow browser

Use:

- compact navigation;
- tabs or drawers for contextual details;
- stacked task content;
- sticky approval actions when appropriate.

## Compact widths

Prioritize:

1. task objective;
2. active status;
3. required user action;
4. primary result;
5. navigation.

Move logs, raw JSON, and secondary metadata into expandable areas.

## Tables

Consider:

- horizontal scroll;
- priority columns;
- detail drawers;
- column visibility.

Do not blindly convert every table to cards.

## Testing

Test at least:

- 1440 px;
- 1200 px;
- 900 px;
- 720 px.

Also test:

- long task titles;
- many steps;
- long error text;
- multiple approval actions;
- empty artifact lists;
- large logs.
